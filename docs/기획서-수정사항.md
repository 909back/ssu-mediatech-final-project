# 기획서 v0.2 → v0.3 수정사항

기획서(PRD v0.2)에서 바뀐 부분만 모았습니다. 각 항목은 "기존"과 "수정"을 나란히 적었고, 기획서 해당 칸을 "수정" 문장으로 바꾸면 됩니다. 결정 근거는 `docs/user-flow.md`(v1~v4)에 있습니다.

## 1. 개요

| 칸 | 기존 | 수정 |
|---|---|---|
| 서비스 이름 | 찰칵 네컷 (가칭) | 도토리네컷 |
| 한 줄 소개 | 브이 손동작 하나로 촬영을 시작하고 | 손바닥을 펴면 촬영이 시작되고, 브이는 마음껏 포즈로 써요 |
| 도구 | p5.js 1.x, ml5.js 1.x | React + TypeScript 앱, 카메라 캔버스는 p5.js 1.x(인스턴스 모드), 인식은 ml5.js 1.x |

## 2. 화면 흐름

기존: 시작 → 프레임 고르기 → 촬영 → 꾸미기 → 저장 (5단계)

수정: 시작 → 프레임 고르기 → **사용법** → 촬영 → 꾸미기 → 저장 (6화면)

- 사용법: 손바닥 그림과 "손바닥을 펴면 시작해요" 한 장. 새로 시작할 때마다 한 번 보여 주고, 촬영에서 뒤로 갔다 다시 오면 건너뜁니다. 단계 표시에서는 "촬영"에 포함합니다.
- 촬영 화면에는 큰 안내 문구를 두지 않고, 손 인식 상태(준비 중, 손바닥을 펴 보세요, 1초 고리, 잠시만요)만 보여 줍니다.
- 모든 화면의 주 버튼은 오른쪽 아래, "뒤로"는 왼쪽 아래에 고정합니다.
- 로고를 누르면 처음 화면으로 갑니다. 찍은 사진이 있으면 먼저 확인합니다.
- 촬영 화면 헤더의 물음표 버튼("사용법 보기" 툴팁)으로 사용법을 다시 볼 수 있습니다.
- 저장 화면 제목은 "네컷이 완성됐어요". 저장한 버튼에는 체크와 "PNG 저장 완료"처럼 완료 표시가 남고, 다시 누르면 한 번 더 저장됩니다.
- 알림은 화면 아래 가운데에 떠서 제목이나 주 버튼을 가리지 않습니다.

## 3. 기능 우선순위

| 기능 | 기존 | 수정 |
|---|---|---|
| 브이 손동작으로 촬영 시작 | P0 | 삭제. 브이는 신호로 쓰지 않음 |
| 손바닥 제스처 | P1 | P0. 촬영 시작과 꾸미기로 넘어가기 둘 다 |
| 프레임 무늬 | P1 | 완료. 테마 5개: 기본, 도토리 숲, 숭실대 캠퍼스, 레트로 픽셀, 가을 낙엽. 숭실대 캠퍼스는 실제 정문과 캠퍼스 사진을 참고했고, 학교 로고와 교표는 넣지 않음 |
| 기본 스티커 | P0 | 완료. 6종을 한 칸에: 도토리 캐릭터, 도토리 얼굴, 도토리, 잎, 하트, 반짝이 |
| 버튼 크기 | 화면마다 따로 지정 | 버튼 컴포넌트에 `hero`(홈 촬영 시작)와 `action`(아래 버튼 줄) 크기를 두고 모든 화면이 같이 씀 |
| 얼굴 필터 | 꾸미기 기능 | 촬영 화면에서 고름. 사진과 GIF, 동영상에 함께 들어감 |
| 2×4 레이아웃 | 기본 방식 미정 | 프레임 고르기에 "4컷 두 장"(같은 4장 두 줄)과 "8컷"(8장 따로)을 따로 둠 |

프레임 고르기 선택지: 4컷(1×4), 6컷(2×3), 4컷 두 장(2×4), 8컷(2×4).

## 4. 인수 기준

| 번호 | 기존 | 수정 |
|---|---|---|
| AC-1 | 1×4를 고르고 "촬영"을 누르면 … 4번 반복 | 그대로. "8컷"을 고르면 8번 반복을 추가 |
| AC-2 | 브이 손동작을 1초 유지하면 진행 고리가 다 찬 뒤 촬영이 시작된다. 0.5초만 하다 내리면 시작하지 않는다. | 촬영 화면에서 **손바닥을 펴고** 1초 유지하면 진행 고리가 다 찬 뒤 촬영이 시작된다. 0.5초만 하다 내리면 시작하지 않는다. **브이를 해도 시작하지 않는다.** |
| AC-2b (새로) | 없음 | 다 찍은 뒤 손바닥을 1초 펴면 꾸미기 화면으로 넘어간다. 촬영을 시작한 손바닥이 그대로 꾸미기로 넘기지 않는다(3초 쿨다운). |
| AC-3 ~ AC-10 | | 그대로 |

## 5. 역할과 파일

기존 기획서는 사람별로 `gesture.js`, `stickers.js` 같은 파일을 나눴습니다. 지금 코드에서는 아래 폴더가 그 역할입니다.

| 담당 | 기존 파일 | 지금 위치 |
|---|---|---|
| A 촬영·저장 | capture, export | `src/screens/shoot/`, `src/screens/save/`, `src/lib/export.ts` |
| B 제스처·얼굴 | gesture.js, face.js, sound.js | `src/lib/gesture.ts`, `src/lib/face.ts`, `src/screens/shoot/useDetection.ts` |
| C 스티커 | stickers.js, cutout.js, filters.js | `src/screens/decorate/`, `src/lib/cutout.ts`, `src/lib/filters.ts` |
| D 화면·프레임 | 화면 전환, 레이아웃 | `src/screens/start/`, `src/screens/frame/`, `src/screens/guide/`, `src/lib/layouts.ts`, `src/lib/compose.ts` |

## 7. 남은 작업

- P0: 기본 스티커 4종(도토리, 잎, 하트, 반짝이) 꾸미기 화면에 추가함 (완료)
- P0: 노트북 웹캠으로 AC-1~10 직접 확인. 특히 AC-2(손바닥 시작), AC-9(강아지 귀 기울기)
- P0: AC-6(누끼 3초), AC-7(GIF 30초), AC-8(WebM 6초) 시간 재기
- P1: 지우개 보정, 셔터 소리, 사람 누끼, 왕눈이 필터 (아직 없음)
- 확인: 개발용 fps 표시가 화면 왼쪽 위에 보이는지
